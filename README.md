# Catch Me

Konum tabanlı, zamanı para olarak kullanan altıgen krallık oyunu.

Tam Firebase, GPS, arka plan bildirimleri, oyun ekonomisi ve iki cihaz test
adımları için [SETUP_TAM_SURUM.md](SETUP_TAM_SURUM.md) dosyasını aç.

Sadece görsel deneme için:

```sh
flutter pub get
flutter run -t lib/visual_preview.dart
```
